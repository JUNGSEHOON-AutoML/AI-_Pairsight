# 동일 사건의 Ollama/Gemini 재판 비교

2026-10-19, `web/scripts/court-run.ts`의 기존 `trusted_edited` 사례를 다시 실행했다. 실제 로컬 이미지 비교 + 가상 후보 페이지로 얻은 카드로 재판한다. 정답과 코드 판정은 모두 **편집 조작**이다. 총 시간은 입력 분석 이후 `runCourt` 시작부터 종료까지이며 모델 로딩 시간은 포함한다.

Gemini의 HTTP 요청은 아직 보내지 않았다. 사용자가 채팅으로 전달한 키를 도구 호출 기록에 복사하지 않고, 서버의 `.env.local` 또는 프로세스 환경에 안전하게 주입되기를 기다리는 상태다. 모의 응답 테스트를 실측 성공이나 모델 정확도로 표기하지 않았다. Gemini 수치가 없으므로 모델 간 속도 우열 결론도 내리지 않는다.

Ollama 0.11.2, CPU 전용 개인 인스턴스(127.0.0.1:11500), 모델별 8스레드, 1회씩 순차 실행했다. 공용 인스턴스와 GPU는 사용하지 않았다. 여러 작업이 실행되는 공유 서버이고 이 작업의 검증도 일부 겹쳤으므로 시간 차이는 모델 크기만의 효과가 아니다. 같은 규칙과 사건을 사용했으나 Gemini는 외부 전송 최소화를 위해 기사 발췌·URL 등을 제거하고 최대 출력 토큰 설정도 다르다. 추후 Gemini 행이 추가되어도 동일 프롬프트/토큰 예산의 엄밀한 성능 비교는 아니다.

기존 조사 시각의 96/164/403초와 이번 값은 별도 실행이다. 최신 표에 기존 측정값을 섞지 않았다. 사례 1건이므로 세 모델의 일반 정확도를 뜻하지 않는다. 3B는 앞선 라이선스 조사대로 연구 비교용으로만 사용하고 운영 모델로 바꾸지 않았다.
