# 실제 사진 보정 결과 — 2026-10-19

판정의 비편집 오탐을 늘리지 않으면서 실제 JPEG를 같은 사진으로 받아들이기 위해 **영역 밖 잔차 상한을 0.008 → 0.020**으로 보정했다. **장면 관문 0.76, 영역 면적 합 8%, 영역 수 2개는 유지**했다. 검증 결과를 본 뒤 값을 다시 맞추지 않았다.

## 자료와 사용 권한

[SkyFinder v1 공개 기록](https://zenodo.org/records/5884485)에 명시된 **CC BY 4.0**을 확인했다. 데이터셋 제공자 Nathan Jacobs·Radu Paul Mihail의 출처 표기, [라이선스 링크](https://creativecommons.org/licenses/by/4.0/legalcode), 변경 내역을 `web/eval/real-photos/ATTRIBUTION.md`에 남겼다. 개별 사진의 URL·아카이브 파일명·날짜·원본/축소본 해시·권리 근거는 `sources.json`에 있다. 게시자의 공개 라이선스 표시를 권리 근거로 사용했으며 각 웹캠 촬영자의 별도 계약을 확보한 것은 아니다.

작은 ZIP 12개를 택한 자원 제한 파일럿이다. 카메라별 날짜가 다른 실제 사진 3장, 총 **36장**을 최대 512px로 보관했다. 원본 해상도 사진·ZIP·페이지 전문은 디스크에 저장하지 않았다. 한 카메라 아카이브에서 디코딩이 불가능한 **14개 파일**을 제외하고 사전 선택 규칙을 적용했다. 야간·안개·렌즈 물방울 사진은 유지했다. 36장 모두 시각적으로 확인했다.

카메라를 분리해 **보정 6대/18장/192쌍**, **검증 6대/18장/192쌍**으로 구성했다. 각 분할은 JPEG 72, 통제된 편집 54, 다른 날짜 36, 다른 카메라 30쌍이다. 고정된 구도의 다른 날짜 사진은 실제 별도 촬영이고, 편집본은 실제 사진에 코드로 가한 패치·copy-move·패치 두 개다. 실제 유포된 허위 사진 수집물이 아니다.

## 범위와 한계

- 실험은 실제 이미지 비교 코드와 v3 판정 규칙을 사용한다. 신뢰 출처·이른 날짜는 평가용 도메인의 통제 변수다. 실제 후보 발견·기사 fetch·게시일 진위·C2PA·팩트체크를 검증한 결과가 아니다.
- 유효한 촬영/편집 기록이 없는 v2 경로는 두 분할 각각 192/192 판단 불가다. 실제 사진에 mock C2PA를 붙여 성능을 부풀리지 않았다. 기존 v2 mock 경로의 보호 조건은 별도 회귀/뮤테이션 테스트로 확인했다.
- 12개 고정 웹캠과 512px 사진은 한국 언론 사진, 스마트폰 재촬영, 원근 변화, JPEG 외 압축, 고해상도 합성이나 정교한 위변조를 대표하지 않는다. 반복 파생 쌍이므로 384개 독립 표본이 아니다.
- 카메라 단위 분리는 이번 기준값 보정에 대한 분리다. DINO의 사전학습에서 이 공개 자료가 노출됐는지는 확인하지 못했다.
- 오탐 0건은 이 표본의 관측치다. 실제 서비스 오탐률 0이나 일반 정확도 보장이 아니다.
- 동일 사진 여부를 잔차만으로 확정할 수 없다. 작은 시점 차이·저대비 국소 편집은 여전히 통과할 수 있다. 다음 보정에서는 새 카메라/새 출처의 검증 자료가 필요하며 이번 검증용 사진으로 값을 다시 맞추면 안 된다.

## 재현 및 인수인계

`web/eval/real-photos/README.md`에 수집·측정·보정·고정·검증 명령과 별도 재현 디렉터리 사용법이 있다. `measurements-calibration.json`, `measurements-validation.json`은 개별 비교 수치, `results.json`은 사례별 기존/새 판정과 집계, `calibration-selection.json`은 후보 선택 근거다. 새로운 테스트는 권리/해시/512px 제한, 카메라 분리, 고정 프로필, 실측 결과 재현을 검사한다.

운영 기본값은 잔차 0.020 / 장면 0.76 / 면적 8% / 2개, `PIPELINE_VERSION=5`다. 기존 서버 재시작과 새 검사가 필요하며 저장된 과거 결과를 자동 재분석하지 않는다.
