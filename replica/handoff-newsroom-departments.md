## 이번 최소 구현

기존 카드 ID를 인용했다는 사실만으로 그 ID 옆에 쓴 자유 문장이 사실이 되지는 않습니다. 기존 검사는 실제 ID를 붙인 새로운 인물·날짜·행위를 걸러내지 못했습니다.

1. 모델이 쓴 자유 문장을 채택하지 않고, 검증한 카드 ID가 가리키는 **기존 카드 요약·기록 날짜**만 코드가 발언으로 구성합니다. 한 주장당 최대 카드 4개입니다.
2. 검증되지 않은 발견 후보는 법정의 `S` 카드로 만들지 않습니다.
3. 서기는 이미 검증된 검사·변호인 주장과 남은 의심만 선택합니다. 유효한 카드 ID를 붙여 새로운 변호 주장이나 의심을 만들 수 없습니다.
4. 기존 판사 v3, 배심원의 판정 상향 금지, 측정값이 뒷받침하는 의심만 판단 불가로 낮추는 제한, 판사의 판단 불가 시 호출 0회, 도구 없는 제공자 경계는 유지합니다.
5. 공개 시연 사례를 새 로직으로 재생성했고 관제실도 재시작했습니다. 모두 mock이며 외부 모델 호출은 없습니다.

이는 기존 근거 카드 자체의 진위를 보증하지는 않습니다. 후보 검증과 사람 검토가 필요합니다. 자유로운 자연어 공방의 표현력을 제한하는 최소 구현입니다.

코드·테스트·시연 데이터 로컬 커밋: **`00e91ba`**. 설계·검증 캡처·이 인수인계는 별도 문서 커밋입니다. push하지 않았습니다.

## 검증 결과

- 전체 **20파일 262개 테스트 통과**. 명령: `npm test -- --maxWorkers=1 --testTimeout=20000`.
- 첫 전체 실행에서는 260개 통과, 기존 이미지 비교 테스트 2개가 기본 5초 제한으로 실패했습니다. 당시 서버의 다른 프로세스들이 CPU를 사용 중이었습니다. 테스트 파일·정답·판정 기준은 바꾸지 않고 동시 실행을 1개로 낮추고 실행 제한을 20초로 늘려 전체를 다시 통과했습니다. 성능 기준을 통과했다는 뜻은 아닙니다.
- 요청한 mock 반례 유지: 인용 없음/없는 카드 거부, 배심원 상향 거부, 같은 장소·다른 시점의 근거 있는 의심으로 하향, 판단 불가면 호출 0회, 페이지 텍스트 주입·도구 사용 차단.
- 새 반례 3개: 실제 카드 ID + 조작된 인물/날짜/행위가 출력·관제실 이벤트에 남지 않음, 서기의 새로운 의심 거부, 미검증 후보 인용 거부.
- `npm run typecheck`, `npm run lint`, `npm run build` 통과.
- Chrome 1280px / 390px 공개 2D 상세: 카드 기반 발언·타임라인·근거 카드·시연 표기 확인. 가로 넘침과 pageerror 0.
- 실제 mock 법정 → WS 어댑터 → 별도 Claw3D: 이벤트 20개, 좌석 7개 작업 시작, 최종 발언 7개, 종료 후 0 working / 7 idle. E1·S1 인용 전달, pageerror 0, 공개 설정 토큰 비노출.
- 캡처와 결과: [clone-screens/stage8-newsroom-court/](clone-screens/stage8-newsroom-court/). 자동 3D 검사는 3460/3470/3471에서 실행 후 종료했습니다.
- Supabase/RLS 서버 테스트는 이번에 재실행하지 않았습니다. DB 스키마 변경은 없습니다. 튜닝 루프도 실행하지 않았습니다.

## 서버·무료 제공자 확인

- CPU 36 논리 스레드, 메모리 125.5 GiB 중 가용 약 72.3 GiB. RTX 3090 24 GiB 3장이 모두 사용 중이어서 이번에는 추론을 실행하지 않았습니다.
- 이전 동일 사건 CPU 실측: Ollama 1.5B 141.895초 / 3B 232.655초 / 7B 439.265초, 각 6회 호출. **이번 발언 제한 보완 전의 측정**이며 새 버전 성능·정확도 측정값이 아닙니다. GPU 속도는 미측정입니다.
- Gemini 무료 한도는 프로젝트별 RPM/TPM/RPD, 실제 값은 계정 화면 확인이 필요합니다. 무료 입력/출력은 개선·사람 검토 대상이 될 수 있습니다. [공식 한도](https://ai.google.dev/gemini-api/docs/rate-limits), [공식 약관](https://ai.google.dev/gemini-api/terms)을 재확인했습니다.
- 뒤이은 사용자 요청으로 기존에 연결한 Gemini 제공자는 유지했습니다. 이번 작업에서는 Gemini·Groq·OpenRouter를 호출하지 않았습니다.
- `.env.local`은 `web/.gitignore`의 `.env*` 규칙으로 제외됨을 확인했습니다. 키 파일을 열거나 수정하지 않았습니다.
