# 공개 사이트: 카테고리 대시보드 (2026-10-19)

운영자가 승인한 사례만 보여주는 공개 화면입니다. 게재 규칙은 [category-policy.md](category-policy.md)에 있습니다.

## 화면

| 경로 | 내용 |
| --- | --- |
| `/cases` | 왼쪽에 주제 메뉴(전체, 정치·선거, 연예·엔터, 사회·재난, 경제, 기타)가 있습니다. 390px에서는 상단의 가로 스크롤 탭으로 바뀝니다. 필터는 조작 유형(AI 생성, 편집 조작, 맥락 조작, 판단 불가)과 유포 경로(제보 기준: 인스타그램, 유튜브, 커뮤니티, 메신저, 기사)이고, 둘 다 URL 쿼리라 공유할 수 있습니다. 카드는 사실 문장 제목, 흐린 이미지, 판정 배지(아이콘 + 글자)로 구성됩니다 |
| `/cases/[slug]` | 판정, 사실 문장, 요약, 흐린 이미지("조작·미확인 이미지 보기"로 독자가 직접 해제)를 먼저 보여줍니다. 그 아래가 **2D 재판 타임라인**입니다: 판사(규칙 v3) → 검사 → 변호인 → 배심원 의심 → 판결(핵심 근거, 남은 의심, 직접 확인하는 법). 모든 주장의 카드 ID는 아래 근거 카드로 이동하는 링크입니다. 규칙에 따라 폐기된 주장은 코드가 쓴 이유만 보여주고, 원문은 공개하지 않습니다 |

캡처는 `clone-screens/stage6-public/`에 있습니다. 1280과 390 너비에서 대시보드, 필터 적용, 상세 2건을 찍었고, 가로 스크롤은 없습니다.

## 데이터

- **스키마:** `public_cases` 테이블(`schema.sql`, `migrations/003`)
  - 승인 상태: `draft`, `pending_review`, `approved`, `rejected`, `withdrawn`
  - 검토자 2명 칸, 내용 플래그, 법무 경고
  - **RLS:** 브라우저(익명이든 로그인이든)는 `approved` 행만 읽고, 쓰기는 못 합니다. 쓰기는 서버(service role)만 합니다.
  - 테스트 12개를 추가했습니다(54/54 통과).
- **앱:** `web/lib/public/store.ts`
  - 지금은 `web/data/public-cases.json`(가상 예시 8건)을 메모리로 읽습니다.
  - DB와 같은 규칙(`publishProblems`)을 통과한 사례만 목록이나 상세에 나옵니다. 승인 전, 반려, 성적 콘텐츠 표시 사례는 상세 주소로 들어가도 없는 페이지로 처리합니다.
- **시드:** `npx tsx scripts/make-public-seed.ts`
  - 합성 fixture를 실제 파이프라인(가상 `.test` 페이지), 판사, 스크립트 에이전트 공방에 통과시켜 만듭니다.
  - 공개 기록에는 페이지 발췌 원문(`untrustedPageText`)을 넣지 않습니다.

## 알려진 점

- 숨긴 사례의 상세 주소는 응답 코드 200과 함께 "찾을 수 없음" 화면(noindex)을 줍니다. Suspense로 스트리밍하는 페이지에서 `notFound()`는 헤더가 이미 나간 뒤라 404 코드를 바꾸지 못합니다. 내용은 노출되지 않습니다(curl로 확인).
- 운영자 승인 화면, Supabase 연결, 제보 접수는 아직 없습니다.
- 시드의 판단 불가 사례는 판사가 판단 불가를 낸 경우뿐입니다. "배심원 의심으로 낮춘" 공개 예시는 아직 없습니다. 근거 카드에 신호가 있는 fixture가 필요합니다.
