# 조사 데스크 후보 발견 — 2026-10-20

## 결정과 실제 동작

SerpApi 네트워크·업로드·키 입력 도구를 제거했다. `SerpApiDiscoveryProvider` 타입만 보존한다. 기존 동의 플래그는 무시하며 외부 이미지 전송 UI도 제거했다.

`CandidateDiscoveryProvider`는 주장 텍스트를 받아 URL 후보만 반환한다. `FactCheckArticleDiscovery`는 기존 한국어 claims:search 피드의 캐시·시간당 6회 예약 한도를 공유한다. 피드에서 접수한 사건은 해당 기사 URL을 자동 사용한다. 다른 사건은 비교할 사진이 있을 때 주장 텍스트로 피드를 조회한다. 수동 후보와 합쳐 URL 중복 제거 후 최대 5개를 확인한다. 가져온 기사에서 최대 6개 이미지를 비교한다(HTML 추출 상한 12개). 한도를 넘는 자료가 없다고 주장하지 않는다.

`GeminiSearchDiscovery`는 **실행 불가를 반환하는 계약 구현**이다. 실제 Google Search 호출 클라이언트나 썸네일 묘사기는 만들지 않았다. 정책 제한을 환경 변수로 해제할 수 없다. SQLite 일일 사용 조회는 미국 태평양 날짜를 사용하되 현재 호출 상한은 **0**이다. 작동하는 검색 쿼터 제어를 완성했다는 의미가 아니다. 후보가 없으면 해당 이유와 수동 후보 링크 요청을 남겨 조사 데스크를 멈추고, 기존 편집장 브리핑의 운영자 할 일로 연결한다.

## Google 공식 조건과 충돌

확인: 2026-10-20. [Gemini 추가 약관](https://ai.google.dev/gemini-api/terms#grounding-with-google-search)은 그라운딩 결과·검색 제안·링크를 해당 질문에 대한 응답으로 함께 사용하도록 한다. URL을 프로그램으로 수집하거나 가져올 페이지를 고르는 데 사용하는 것이 금지 사례에 포함된다. 따라서 요청한 ‘검색 URL 수집 → PolicyFetch → 이미지 검증’은 현재 조건에 맞지 않는 것으로 해석했다. 요청 시점의 한 페이지만 가져오더라도 이 용도 충돌은 해소되지 않는다.

[검색 그라운딩 문서](https://ai.google.dev/gemini-api/docs/google-search)는 검색 제안 표시 정보를 반환한다. 결과를 표시하려면 질문한 사용자에게 관련 검색 제안을 함께 보여야 한다. 일반적인 캐시·분석·저장은 제한되며, 약관의 제한된 표시 평가/개인 대화 기록 예외를 후보 DB 구축에 적용하지 않는다. 따라서 이번 구현은 그라운딩 응답, URL, HTML, 검색 제안, 이미지 묘사를 **수신·보관하지 않는다**. Google의 30일 서버 보관 설명은 앱의 30일 캐시 허가가 아니다.

무료 서비스의 입력·출력은 제품 개선에 쓰이고 사람 검토 대상이 될 수 있다. 일반 방문자 원본·썸네일은 전송하지 않는다. 운영자 썸네일도 이번에는 전송하지 않는다. 허용되는 별도 용도가 정해지기 전에는 불필요한 묘사 호출을 하지 않는다. 기존 법정/보고서 Gemini Provider는 계속 텍스트 근거 요약만 사용한다.

## 무료 한도와 키 확인

[공식 가격표](https://ai.google.dev/gemini-api/docs/pricing#gemini-2.5-flash)는 Gemini 2.5 Flash/Flash-Lite 무료 검색 그라운딩을 두 모델 합산 최대 500 RPD로 표시한다. 이는 특정 키의 사용 가능량 보증이 아니다. 추가 약관의 Paid Service 문구와 가격표의 무료 할당도 구분해야 한다. Gemini 3 이후 모델의 가격을 여기에 대입하지 않는다.

[한도 문서](https://ai.google.dev/gemini-api/docs/rate-limits)에 따르면 한도는 프로젝트별이며 RPD는 미국 태평양 자정에 초기화된다. 활성 RPM/TPM/RPD는 AI Studio에서 확인한다.

실제 저장된 `GEMINI_API_KEY`로 `models/gemini-2.5-flash` 모델 정보 GET 1회를 보냈고 HTTP 200을 받았다. 응답 본문·키는 기록하지 않았다. 이것은 인증·모델 조회 성공만 의미한다. 프로젝트 등급·잔여 한도·검색 호출 가능량은 **미확인**이다. 약관 충돌 때문에 검색 생성 호출은 0회이며, 부하를 줘서 한도를 소진하는 검사는 하지 않았다. 결제 설정은 변경하지 않았다. `.env.local`은 gitignore 대상이다.

## 사진 근거의 경계

후보 URL이나 다른 기관의 평가만으로 근거를 만들지 않는다. 기존 PolicyFetch의 robots·SSRF·속도 제한·유료벽/봇 차단 정책을 거친 뒤, 기존 장면 관문과 픽셀 비교를 사용한다. 기사 이미지 일부라도 fetch에 실패하면 부서를 멈춘다. Fact Check 경로의 기사 평가·발췌는 근거에서 제거하며, 사진 일치·출처 URL·게시일 관측만 전달한다. 페이지 게시일은 사진 촬영일로 승격하지 않는다. 판정 규칙과 승인 조건은 변경하지 않았다.

피드 후보 검색 오류가 있어도 다른 후보가 있으면 해당 오류를 보고서에 남기고 그 후보를 확인한다. 후보가 전혀 없으면 수동 링크 보충을 요청한다. 성공한 페이지 fetch, 기사 대표 사진의 자기 비교, Gemini 설명은 사건 진위 검증 성공이 아니다.

검증 사진은 512px 이하 썸네일만 보관하며, 전문·고해상도 파일·원문 오류는 저장하지 않는다. 기존 외부 기관의 평가는 모니터링 화면 참고 정보로만 남고 새 법정 근거 카드는 되지 않는다.

실제 Fact Check 연결 확인: 한국어 `네팔 홍수` query 1회가 성공했고 최대 5개 후보를 반환했다. 새 Provider 출력 필드는 `url`, `provider`뿐이다. 검색 성공은 페이지 접근 또는 사진 검증 성공을 뜻하지 않는다.
