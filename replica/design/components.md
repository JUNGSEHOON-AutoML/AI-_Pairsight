## 1. 먼저 설계한 화면: 판단 불가 · 원본 없음

두 화면 모두 결과 화면(S03)의 한 상태입니다. 같은 뼈대를 쓰고, 아래 네 블록을 **항상 이 순서로** 보여줍니다.

| 순서 | 블록 | 내용 |
| --- | --- | --- |
| 1 | **확인한 항목** | 실행한 검사 목록과 각각의 결과. 예: 원본 검색 ✓ 완료, 출처 증명(C2PA) ✓ 없음, 워터마크 ✓ 없음, AI 탐지 ✓ 완료 |
| 2 | **찾은 것** | 찾은 근거를 강한 순서로 나열. 아무것도 없으면 "판정에 쓸 만한 근거를 찾지 못했어요" |
| 3 | **부족한 근거** | 판정에 필요한데 얻지 못한 것. 예: "같은 사진의 다른 기록이 없어요", "날짜를 확인하지 못했어요" |
| 4 | **할 수 있는 일** | 사용자가 다음에 할 행동 버튼(아래 참고) |

### 1-1. 판단 불가 (`verdict = inconclusive`)

```
┌──────────────────────────────────────────────────────────┐
│ (circle-help) 판단 불가                                  │  ← VerdictBanner (unsure)
│ 단, 2019-03-02(게시) ○○ 페이지에 같은 장면의 사진이 있으며, │  ← 핵심 발견 (v3, 있을 때만)
│     오른쪽 아래 영역이 달라요. [신뢰 출처] [출처 보기]      │
│ 결론을 내릴 만큼 강한 근거가 없어요.                      │  ← 한 줄 이유
│ 진짜라는 뜻도, 가짜라는 뜻도 아니에요.                    │
│ 확인 시각 2026-10-18 21:40 · [재검사]                     │  ← CheckedAt + Recheck
├──────────────────────────────────────────────────────────┤
│ 확인한 항목                                              │
│  ✓ 원본 검색          같은 사진 0건                       │
│  ✓ 출처 증명 (C2PA)   기록 없음                           │
│  ✓ 워터마크           찾지 못함                           │
│  ✓ AI 탐지            완료 (참고용)                       │
├──────────────────────────────────────────────────────────┤
│ 찾은 것                                                  │
│  [EvidenceCard: AI 탐지 · 약 · 영향 없음]                 │
├──────────────────────────────────────────────────────────┤
│ 부족한 근거                                              │
│  • 같은 사진의 다른 기록이 없어요                         │
│  • 파일에 출처 기록(C2PA)이 없어요                        │
├──────────────────────────────────────────────────────────┤
│ 할 수 있는 일                                            │
│  [원본 파일로 다시 검사] [며칠 뒤 재검사 알림] [출처를 아는 사람에게 묻기 (공유)] │
├──────────────────────────────────────────────────────────┤
│ ▸ 상세 점수 (접힘)                                       │
│ 고지: 자동 분석에는 오류가 있을 수 있어요. 이 결과만으로 누군가를 비난하지 마세요. │
└──────────────────────────────────────────────────────────┘
```

- AI 탐지 점수는 "찾은 것" 안에서 **약** 배지를 단 일반 카드로만 보여줍니다. 점수 숫자는 "상세 점수"를 펼쳐야 보입니다.
- "할 수 있는 일"의 버튼 세 개:
  - **원본 파일로 다시 검사:** 캡처나 재전송 대신 원본 파일을 넣어 보라는 안내입니다. C2PA와 EXIF가 살아 있을 수 있습니다.
  - **며칠 뒤 재검사 알림:** 새로 퍼진 이미지는 검색 색인에 아직 없을 수 있습니다. 가입한 사용자만 쓸 수 있고, 비회원에게는 가입 안내를 보여줍니다.
  - **공유해서 묻기:** S10 공유 링크로 출처를 아는 사람에게 물어봅니다.

### 1-2. 원본 없음 (상태: `source_match` 결과가 0건)

원본 없음은 **판정이 아니라 상태**입니다. 다른 강한 근거가 있으면 판정은 따로 나옵니다. 예를 들어 C2PA에 AI 생성 기록이 있으면 판정은 AI 생성입니다. 원본 비교 블록 자리에 아래 내용이 들어갑니다.

```
┌──────────────────────────────────────────────────────────┐
│ (search-x) 원본 없음                                      │
│ 다른 곳에서 같은 사진을 찾지 못했어요.                     │
│ 원본이 없다고 가짜라는 뜻은 아니에요.                      │
│                                                          │
│ 이런 경우에 원본이 안 나올 수 있어요                       │
│  • 방금 찍었거나 처음 올라온 사진                          │
│  • 비공개 계정, 단톡방, 카페처럼 검색되지 않는 곳에만 있는 사진 │
│  • 많이 잘리거나 필터를 입힌 사진                          │
│                                                          │
│ 검색한 곳: Google · TinEye     (검색 제공자 목록)          │
│ [잘리지 않은 원본으로 다시 검사] [재검사]                  │
└──────────────────────────────────────────────────────────┘
```

## 2. 결과 화면 (S03) 순서

모든 판정이 같은 순서를 씁니다. **AI 탐지 점수를 크게 띄우지 않습니다.**

| 순서 | 블록 | 규칙 |
| --- | --- | --- |
| 1 | **판정 + 한 줄 이유** (VerdictBanner) | 아이콘 + 판정 이름 + 이유 한 줄. 아래에 확인 시각과 재검사 버튼 |
| 2 | **근거 카드** (EvidenceCard 목록) | 강한 순서로 정렬. 강도 배지가 같으면 종류 순서로 정렬: 원본 일치 → 출처 증명(C2PA) → 워터마크 → 팩트체크 기록 → 촬영 정보(EXIF) → AI 탐지 → 화면 재촬영 |
| 3 | **원본 비교** (CompareView) | 원본 일치가 있을 때만 표시. 없으면 1-2의 "원본 없음" 블록 |
| 4 | **상세 점수** (DetailsDisclosure) | **기본 접힘.** AI 탐지 점수, 각 제공자의 원본 값, 파이프라인 버전 |
| 5 | **고지문** (Disclaimer) | 항상 표시 |

판정별 한 줄 이유 예시 (판정 이름 옆에 그대로 씀):

| 판정 | 한 줄 이유 예시 |
| --- | --- |
| 진짜 확인 | 같은 사진의 이른 기록을 찾았어요. 달라진 곳은 없어요. |
| AI 생성 | 파일의 출처 기록(C2PA)에 AI 생성 도구가 적혀 있어요. |
| 편집 조작 | 원본을 찾았어요. 원본에서 달라진 곳이 2군데 있어요. |
| 맥락 조작 | 이 사진은 2019-03-02 이전에 이미 있었어요. (TinEye가 처음 발견한 날짜) |
| 판단 불가 | 결론을 내릴 만큼 강한 근거가 없어요. |

## 3. 컴포넌트

### VerdictBanner

```
variants  authentic, ai_generated, edited, miscontextualized, inconclusive
layout    아이콘 24px + 판정 이름 (type lg/600) + 판정 근거 강도 배지(있을 때) / 한 줄 이유 (base) / CheckedAt + RecheckButton
          판단 불가: 제목 바로 아래에 HeadlineLine("단, …")을 먼저, 그 아래 이유(sm)
          다른 판정: 이유 아래에 HeadlineLine("핵심 발견: …")
tokens    bg verdict-{v}-bg, 판정 이름 verdict-{v}, 본문 text, border-left 4px verdict-{v}, radius lg
icons     badge-check, bot, scissors, calendar-x, circle-help (glossary.md)
a11y      <section aria-labelledby>. 판정 이름은 <h2>로 둬서 스크린리더가 "판정: AI 생성"으로 읽게 함
          색만으로 구분하지 않음: 아이콘 + 글자를 항상 함께 표시. 아이콘은 aria-hidden
used on   S03, S10
```

### HeadlineLine (핵심 발견) · v3

```
data      headlineFinding { kind, text, sourceUrl, sourceName, trusted, date, dateSource }
priority  팩트체크(같은 이미지·주장) > 신뢰 출처 차이 > 신뢰 출처 같은 사진 > 다른 출처 차이 > 다른 출처 같은 사진(날짜 있음)
          > 서명된 C2PA > 다른 출처 같은 사진(날짜 없음). 아무것도 없으면 표시하지 않음
layout    판단 불가: "단, " + text (base/600) · 다른 판정: "핵심 발견: " + text (sm)
          trusted이면 [신뢰 출처] 태그(아이콘 shield-check + 글자), sourceUrl이 있으면 [출처 보기] 새 창 링크
rules     판정처럼 읽히는 말(가짜, 조작했다)을 쓰지 않음. 날짜에는 항상 (게시)/(보관 기록)/(검색 발견)
used on   S03, S10
```

### EvidenceCard

```
variants  source_match, c2pa, watermark, fact_check, exif, pixel_model, screen_recapture
layout    [종류 아이콘] 근거 이름 · StrengthBadge · 결과(진짜 쪽 근거 / 조작 쪽 근거 / 영향 없음 / 확인 못 함)
          요약 한 줄 / 출처 링크(SourceLink) / 날짜(DateWithSource)
states    default, expanded(세부 내용), unavailable(회색 처리 + "확인 못 함" + 이유)
tokens    bg bg, border border, radius md, shadow card
a11y      <article>. 결과는 글자로도 표시(아이콘만 쓰지 않음)
          pixel_model 카드는 점수를 숫자로 크게 띄우지 않음. "AI 탐지 모델 점수가 높아요 (참고용)"처럼 문장으로 표시하고, 숫자는 DetailsDisclosure에만 둠
used on   S03, S10
```

종류별 아이콘: 원본 일치 `image`, C2PA `shield-check`, 워터마크 `fingerprint`, 팩트체크 기록 `file-badge`, EXIF `info`, AI 탐지 `scan-eye`, 화면 재촬영 `monitor`

### StrengthBadge (근거 강도 배지, 하나로 통일)

```
variants  strong(강), medium(중), weak(약)
layout    막대 3칸 (켜진 칸: strength-on, 꺼진 칸: strength-off) + 글자 "강"/"중"/"약"
          강 ■■■ 강 · 중 ■■□ 중 · 약 ■□□ 약
tokens    막대 8×4px, gap 2px, radius sm, 글자 xs/500 text
a11y      aria-label="근거 강도: 강". 막대는 aria-hidden. 색이 아니라 칸 수와 글자로 구분
used on   모든 EvidenceCard. 이 배지 외의 강도 표시(%, 별점, 신호등)는 쓰지 않음
```

### CompareView (원본 비교)

```
variants  desktop: 나란히 보기 (md 768px 이상)
          mobile:  겹치기 + 슬라이더 (md 미만)
layout    desktop  [원본 | 넣은 이미지] 두 칸, 같은 높이, 아래에 각 이미지의 출처·날짜
          mobile   한 칸에 두 이미지를 겹치고, 가로 슬라이더로 경계를 이동. 기본 위치 50%
          공통     차이 영역 표시 토글 (highlight 테두리 2px + 번호)
                   차이 목록을 글로도 표시: "1. 오른쪽 위 간판의 글자가 바뀌었어요"
states    loading(두 칸 스켈레톤), one-missing(원본 이미지를 불러오지 못함 → 원본 페이지 링크만), no-diff("달라진 곳을 찾지 못했어요")
a11y      슬라이더는 <input type="range"> + aria-valuetext="원본 50%". 키보드 ←/→ 5% 단위 이동
          히트맵이나 차이 영역에는 항상 글 설명 목록을 함께 둠 (색만으로 전달 금지)
used on   S03, S04
```

### HeatmapNote (히트맵 글 설명) · could 기능

```
히트맵을 표시할 때는 반드시 바로 아래에 글 설명을 둠:
"색이 진한 곳일수록 AI 탐지 모델이 의심한 부분이에요. 모델의 추정일 뿐, 조작된 곳이라는 증거는 아니에요."
의심 영역이 있으면 위치를 글로 나열 (예: "얼굴 왼쪽, 배경 하늘")
```

### CheckedAt + RecheckButton (모든 결과에 표시)

```
layout    (clock) 확인 시각 2026-10-18 21:40 · [refresh-cw 재검사]
rules     확인 시각 = analyses.finished_at, 사용자 현지 시각으로 표시하고 툴팁에 UTC 표시
          재검사는 새 검색 결과로 다시 분석. 무료 횟수 1회를 차감한다는 사실을 버튼 옆에 표시
          24시간 안의 재검사는 "결과가 같을 가능성이 커요" 안내
states    default, loading, disabled(무료 횟수 소진 → 이유를 글로 표시)
used on   S03, S10(공유 페이지에서는 재검사 버튼 대신 "나도 검사하기")
```

### DateWithSource

```
항상 "날짜 · 날짜의 출처" 형태. 금지 표현: "최초 게시일"
예  2019-03-02 · TinEye가 처음 발견한 날짜 (실제 게시일은 더 이를 수 있음)
    2019-02-28 · 페이지에 적힌 게시일
```


## 4. 직접 설계한 화면 [신규]

### 4-1. 분석 중 (S02) [신규]

```
┌───────────────────────────────────────┐
│ (loader-circle) 근거를 모으고 있어요    │
│                                       │
│  ✓ 이미지 확인         완료            │
│  ◐ 원본 검색           진행 중         │  ← ProgressSteps (실제 파이프라인 단계와 1:1)
│  ○ 출처 증명·워터마크   대기            │
│  ○ 판정                대기            │
│                                       │
│ 보통 10~30초 걸려요. 이 창을 닫아도 기록에 남아요(가입한 경우). │
│ [취소]                                 │
└───────────────────────────────────────┘
```

- 가짜 진행률 막대는 쓰지 않습니다. 실제로 끝난 단계만 체크합니다.
- 60초가 넘으면 "평소보다 오래 걸리고 있어요" 안내를 보여주고, 취소 버튼을 강조합니다.
- a11y: 단계가 바뀔 때 `aria-live="polite"`로 단계 이름을 읽어줍니다.
- 줄인 동작 설정(`prefers-reduced-motion`)이 켜져 있으면 spinner를 멈춥니다(tokens.css 반영).

### 4-2. 분석 실패 (오류) [신규]

```
┌───────────────────────────────────────┐
│ (triangle-alert) 분석하지 못했어요      │
│ 이번 검사는 무료 횟수에서 빼지 않았어요. │  ← 리뷰 불만 #9(실패에도 차감)에 대한 답
│                                       │
│ 이유: 원본 검색 서비스가 응답하지 않았어요. │  ← error_code를 사람 말로 바꾼 것
│ [다시 시도] [다른 이미지 검사]           │
└───────────────────────────────────────┘
```

| error_code | 화면 문구 |
| --- | --- |
| unsupported_type | JPG, PNG, WebP, HEIC 이미지만 검사할 수 있어요. |
| too_large | 10MB보다 큰 이미지는 검사할 수 없어요. |
| url_no_image | 이 페이지에서 이미지를 찾지 못했어요. |
| url_blocked | 이 페이지는 가져올 수 없어요. (로그인이 필요하거나 접근이 막힌 페이지) |
| provider_timeout | 원본 검색 서비스가 응답하지 않았어요. |
| internal | 알 수 없는 문제가 생겼어요. |

### 4-3. 무료 횟수 소진 [신규]

```
┌───────────────────────────────────────┐
│ (timer-off) 오늘 무료 검사를 다 썼어요   │
│ 무료 횟수는 매일 오전 9시(한국 시각, UTC 0시)에 다시 채워져요. │
│                                       │
│ 지금까지 검사한 결과는 그대로 볼 수 있어요. │
│ [가입하고 기록 저장하기] [요금제 보기]    │
│                                       │
│ 결제 정보 없이 가입할 수 있어요.         │
└───────────────────────────────────────┘
```

- 막힌 순간에 결제를 강요하지 않습니다. 첫 버튼은 가입이고, 요금제는 두 번째 버튼입니다.
- 별점 요청 팝업은 이 화면을 포함해 어디에서도 첫 사용 전에 띄우지 않습니다(리뷰 불만 #2).
- 초기화 시각은 사용자 현지 시각으로 바꿔 표시합니다. 위 예시는 한국 기준입니다.

## 5. 자주 쓰는 문구 (용어집 기준)

| 위치 | 문구 |
| --- | --- |
| S01 입력 안내 | 의심되는 이미지를 넣거나, 이미지가 있는 페이지 주소를 붙여 넣어 주세요 |
| S01 메인 버튼 | 근거 찾기 |
| S01 URL 범위 안내 | 페이지 속 이미지만 확인해요. 기사 내용이 사실인지는 확인하지 않아요. |
| S02 분석 중 | 근거를 모으고 있어요 |
| S03 판정 | 진짜 확인 / AI 생성 / 편집 조작 / 맥락 조작 / 판단 불가 |
| S03 고지 | 자동 분석에는 오류가 있을 수 있어요. 이 결과만으로 누군가를 비난하지 마세요. |
| 원본 없음 | 다른 곳에서 같은 사진을 찾지 못했어요. 원본이 없다고 가짜라는 뜻은 아니에요. |
| 재검사 버튼 | 재검사 (무료 횟수 1회) |
| 오류 | 분석하지 못했어요. 이번 검사는 무료 횟수에서 빼지 않았어요. |
| 한도 소진 | 오늘 무료 검사를 다 썼어요 |
| 빈 기록 (S06) | 아직 검사한 이미지가 없어요. 처음 하나를 넣어 보세요. |
| 판정 이유: 편집 조작 (v3) | 신뢰 출처 원본과 달라요: {출처}에 {날짜} {게시/보관 기록}된 사진과 비교하면 {위치} 영역이 달라요(차이가 여러 곳이면 "{위치} 등 {n}군데가"). 누가 왜 바꿨는지는 판단하지 않아요. |
| 판정 이유: 맥락 조작 (v3) | 신뢰 출처({출처}) 페이지에 같은 사진이 {날짜} {게시} 날짜로 있어요. 알려준 날짜({날짜})보다 {기간: 45일 / 약 3개월 / 약 8년} 일러서 맞지 않아요. |
| 판정 이유: 충돌 (v3) | 서명된 촬영 기록과 신뢰 출처 사진의 차이가 서로 맞지 않아요. 추가 검증이 필요해요. |
| 핵심 발견: 차이 | {날짜}({게시}) {출처} 페이지에 같은 장면의 사진이 있으며, {위치} 영역이 달라요. |
| 핵심 발견: 같은 사진 | {날짜}({게시}) {출처} 페이지에 같은 사진이 있어요. |
| 핵심 발견: 팩트체크 | 팩트체크 기관이 같은 이미지·같은 주장을 이미 검증했어요 ({도메인}). |
| 핵심 발견: 출처 기록 | 파일에 서명된 출처 기록(C2PA)이 있어요. |
| 부족한 근거 (v3) | 알려준 촬영 날짜가 없어 신뢰 출처 게시일과 비교하지 못했어요 / 신뢰 출처 게시일이 알려준 날짜보다 30일 이상 이르지 않아요 / 신뢰 출처 페이지의 게시일을 확정하지 못했어요 |
