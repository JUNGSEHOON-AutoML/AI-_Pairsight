# SerpApi Google Lens 후보 발견 (공식 문서 확인 2026-10-20)

[공식 가격표](https://serpapi.com/pricing): 무료 월 250회, 시간당 처리량 50회. 성공 검색만 월 사용량에 포함하고 캐시·오류·실패 검색은 제외한다고 명시한다. 결제와 업그레이드를 구현하지 않는다. [Account API](https://serpapi.com/account-api)는 무료이며 검색 한도를 소모하지 않는다. 검색 전 무료 플랜 이름·가격 0·남은 plan_searches_left를 확인하고 확인 불가나 유료 계정이면 중단한다.

자체 SQLite 카운터는 최근 31일 250회, 최근 1시간 50회로 더 보수적이다. 달력 월 초기화 대신 갱신일 차이를 피하는 이동 기간이다. 검색/업로드 전에 트랜잭션으로 예약하고 실패도 차감한다. 프로세스 재시작·동시 요청에도 유지된다. 같은 이미지 해시 결과는 1시간 재사용. 로컬 제한 또는 서버 429는 자동 재시도 없이 후보 링크 보충 작업과 편집장 브리핑으로 이어진다. 다른 앱이 같은 키를 쓰면 공급자 잔여량 확인이 추가로 보호한다.

[Google Lens 문서](https://serpapi.com/google-lens-api): 공개 이미지 URL 또는 image_id 검색을 지원한다. 후보만 발견하며 원본·진위를 확정하지 않는다. 최대 5개 후보 URL을 저장하고 기존 robots/SSRF/속도 제한/유료벽·봇 차단 정책으로 해당 페이지만 검증한다. SNS 결과는 후보 fetch 대상에서 제외한다. 원본 고해상도·결과 원문·기사 전문을 저장하지 않는다.

localhost URL을 Google에서 가져오는 것은 불가능하다. 포트 포워딩만 된 로컬 개발 주소도 공개 이미지 URL이 아니다. 공개 기사 이미지 주소는 사용 가능하다. 업로드 사진은 [Image API](https://serpapi.com/image-api)에 JPEG 썸네일(최대 512px, 메타데이터 제거, 500KB 이하)을 보내 image_id로 검색할 수 있다. ID 유효기간은 10분이며 코드에 영구 저장하지 않는다. 외부 업로드를 별도 허용한 경우에만 사용한다. 터널·Supabase 공개 버킷·고해상도 원본 공개는 필요 없다. 업로드를 허용하지 않거나 검색이 불가능하면 운영자 수동 후보 링크로 전환한다.

[이용약관·개인정보 정책](https://serpapi.com/legal)의 검색 자료 보관 기간은 31일이다. image_id 만료는 이미지 즉시 삭제 보장이 아니다. 무료 플랜에 ZeroTrace가 있다고 가정하지 않는다. 저작권·개인정보 등 법 준수 책임은 사용자에게 남으며 검색 결과를 유일한 근거로 사용하지 않는다. 무료 플랜에는 약관의 U.S. Legal Shield 보장이 적용되지 않는다.

키는 원래 프로젝트 web/.env.local의 SERPAPI_API_KEY에 운영자가 직접 입력한다. 값이나 요청 URL·계정 응답·오류 본문을 출력/저장하지 않는다. 외부 요청은 고정 serpapi.com, 리다이렉트 금지, 응답 크기 제한·타임아웃을 적용한다. 키 미설정 시에도 나머지 편집국·수동 후보 처리는 동작한다. 실제 연결 여부는 인수인계 문서의 검증 결과를 참조한다.
