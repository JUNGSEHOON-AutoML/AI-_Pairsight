# 다섯 데스크와 편집장 (2026-10-20)

기존 9개 작업 함수와 판정·법정·승인 규칙을 그대로 호출하고, 읽는 단위를 접수 → 조사 → 판정 → 검토 → 발행으로 묶었다. 신뢰성 지연/실패/사람 평가 지표는 편집장 브리핑에 들어간다. 코드 작업 뒤 실제 LLM이 허용된 사실 ID의 순서를 구성한다. 원문 문장은 코드가 조립하므로 LLM이 사실·날짜·진위 판정을 새로 쓸 수 없다. 이는 기존 법정의 인용 검증과 같은 방식이다. 보고서 전용 기본 로컬 모델은 qwen2.5:1.5b이며 PAIRSIGHT_REPORT_MODEL로 변경한다. 법정 모델 설정은 유지한다. 코드·LLM 중단 시에는 code-fallback 마크다운에 중단 이유를 명시하고 인계하지 않는다.

| 데스크 | 코드 기능 | 보고서·인계 |
|---|---|---|
| 접수 | 분류·중복 묶음·입력 지시문/반복 제보 | 01-접수.md |
| 조사 | 외부 후보 검색·robots 페이지 검증·날짜·이미지 비교·히트맵·페이지 지시문 검사 | 02-조사.md |
| 판정 | 기존 v3 코드 판정, 검사·변호인·배심원·서기 법정 | 03-판정.md |
| 검토 | 법무 경고·사람 승인 대기 | 04-검토.md, 사람 승인 전 인계 금지 |
| 발행 | 승인한 사실 제목·공개 카드·직접 확인 안내 | 05-발행.md |
| 편집장 | 실제 상태·지연·실패·평가·조치 목록 | 사건 브리핑, 한국 시간 날짜당 일일 브리핑 |

보안 검사는 접수 때 입력·반복 제보를 검사하고, 조사 뒤 같은 기존 작업 함수를 다시 호출해 가져온 페이지의 지시문 신호를 갱신한다. SNS 계정 수집은 하지 않는다. 기존 사건은 코드 기록을 `legacy` 보고서로 이관하며 LLM 작성으로 표시하거나 작업 애니메이션을 재생하지 않는다. 판정·승인·실패 상태를 바꾸지 않는다.

보고서와 지침 형식은 ../newsroom/README.md에 있다. SQLite는 상태·인덱스·문서 해시를 보관한다. 사람이 읽는 내용은 newsroom/cases 및 newsroom/briefings의 마크다운이다. 파일 해시가 다르거나 검사 실패 시 인계·승인 차단. 지침 변경은 다음 작성부터 반영하며 보고서에 해당 지침의 해시를 남긴다. LLM에 도구 권한은 없다.

편집장 브리핑은 완료·중단·승인 대기·반려·철회마다 상태 서명으로 중복을 방지한다. 일일 브리핑은 워커가 켜져 있는 동안 한국 시간 하루 한 번 작성한다. 서버가 꺼졌던 날의 보고서를 소급 생성하지 않으며 다시 켠 날부터 작성한다. LLM 장애나 보호 검사 실패 때는 `코드 비상 현황`이라고 분명히 표시해 운영자 할 일을 숨기지 않는다. 비상 브리핑도 판정이나 상태를 변경하지 않는다.

운영자 /newsroom: 좌측 최신 브리핑·할 일·사건 목록, 우측 Claw3D. 사건 상세는 5개 문서와 검토 옆 승인, 근거·공방 펼쳐보기. 내부 상태는 보존하고 화면은 확인 중 / 사람 검토 필요 / 완료로만 묶는다. 실패·반려·철회 이유는 숨기지 않는다. 정치·선거 2인 승인, 콘텐츠 게재 금지, 철회는 기존 규칙 그대로다.

방문자 /check: 사진 또는 URL + 질문만 필수. 외부 썸네일 검색은 선택이다. 접수 브라우저에 HttpOnly 소유권 쿠키를 발급하고 DB에는 해시만 저장한다. UUID만 알아서는 비공개 접수 조회 불가. 사람 승인 전에는 진행 상태만 보여주고, 승인 후 결론·핵심 근거 3개·접힌 공방 표시. 비영리 시범 접수 제한은 브라우저당 시간당 3건, 전체 하루 20건이다. 쿠키 접근 유효기간은 30일이며 데이터 자동 삭제 기간을 뜻하지 않는다.

Claw3D 별도 앱의 빌더 OfficeMap 모델로 7개 구역을 배치했다. 좌표는 배치 파일에서 읽고, 보고서 완료 이벤트가 있을 때 해당 직원이 문서를 들고 편집장에게 이동한다. 브리핑 완료 이벤트는 편집장 → 운영자 이동이다. 첫 연결·재연결·중복 스냅샷에서는 과거 작업을 재생하지 않는다. 실제 작업 상태만 타이핑하며, 인위적 대기 시간을 코드 처리에 넣지 않는다. 운영 화면은 배치/판정/설정 수정 불가, localhost 전용, OpenClaw·Hermes 미사용.
